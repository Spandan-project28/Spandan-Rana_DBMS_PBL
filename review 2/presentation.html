3. Advanced DDL Scripts & Integrity Constraints

Enforcing zero segment collisions, non-negative fares, chronological sequences, and queue uniqueness

Business Integrity
Business Rule 1

No Overlapping Seat Segments

Enforces that a single physical seat cannot be double-booked across overlapping stop sequences on the same train journey.

CREATE TRIGGER trg_check_segment_overlap BEFORE INSERT ON Journey_Segment FOR EACH ROW BEGIN IF EXISTS ( SELECT 1 FROM Journey_Segment s JOIN Route_Stop r1 ON s.SourceRouteID = r1.RouteID JOIN Route_Stop r2 ON s.DestRouteID = r2.RouteID WHERE s.SeatID = NEW.SeatID AND s.ScheduleID = NEW.ScheduleID AND s.Status = 'CONFIRMED' AND NOT (NEW_Dest_Seq <= r1.StopSequence OR NEW_Src_Seq >= r2.StopSequence) ) THEN SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = 'Seat segment collision detected!'; END IF; END;
Business Rule 2

Unique Waitlist Position & Ordering

Ensures no two passengers share the same queue position for a given train journey schedule.

CREATE TABLE Waitlist ( WaitlistID INT PRIMARY KEY, PNRID INT NOT NULL, ScheduleID INT NOT NULL, Position INT NOT NULL CHECK (Position > 0), Status VARCHAR(20) DEFAULT 'WAITING', UNIQUE (ScheduleID, Position), FOREIGN KEY (PNRID) REFERENCES Booking(PNRID) );
Business Rule 3

Non-Negative Fares & Refund Constraints

Protects database from arithmetic corruption and invalid refund amounts.

ALTER TABLE Booking ADD CONSTRAINT chk_fare_non_negative CHECK (TotalFare >= 0.00); ALTER TABLE Payment ADD CONSTRAINT chk_payment_amount CHECK (Amount >= 0.00);
Business Rule 4

Chronological Stops & Stop Sequence Integrity

Guarantees train stops occur in ascending order with positive distances.

ALTER TABLE Route_Stop ADD CONSTRAINT chk_stop_seq CHECK (StopSequence > 0 AND Distance >= 0); ALTER TABLE Route_Stop ADD CONSTRAINT chk_times CHECK (DepartureTime >= ArrivalTime);
